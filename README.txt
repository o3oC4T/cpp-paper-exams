컴퓨터언어 II · 지필 모의고사

20문항 × 5회분, 핵심 정리 10개 주제, 개념 공부 8개 단원.
강의 PDF의 실제 화면에서 확인한 색 강조와 사용자가 제공한 시험 유형을 바탕으로 구성했습니다.
해설과 핵심 정리에 자료명 및 PDF 쪽수를 명시했습니다.
추가 교재: 황기태의 명품 C++ Programming 3판 (C++ Programming.pdf).
교재 2장 및 3장의 해당 개념과 대조하고 해설 및 핵심 정리에 교재 쪽수도 표시했습니다.
8번과 15번은 구체적인 원문이 주어지지 않아 수업 범위에서 유형을 보완했습니다.

기능
- 객관식, 복수 정답, O/X, 한 줄 코드, 출력 예측, 코드 서술형
- 답안의 브라우저 로컬 저장, 회차별 이어 풀기, 다시 볼 문제 표시
- 제출 후 해설과 자료 근거, 서술형 직접 채점
- 입력 답안과 정답이 제외된 시험지 인쇄, 제출 후 해설 인쇄
- 비교표와 코드 예제를 포함한 핵심 정리
- 개념 공부: 단계별 설명 47개, 코드 실행 추적 8종, 이해 확인 34문항
- 기본 문법, 문자열, 연산자·반복문, 배열·포인터, 함수, 클래스, 생성·소멸, 접근 지정자
- 반복 끝값 변경, 두 객체의 독립된 값 변경, 포인터 대상 변경과 역참조 대입 실습
- 읽은 단계·퀴즈 답안·마지막 학습 위치 저장, 관련 모의고사 문항 바로가기

개념 공부: #/learn
클래스부터 시작: #/learn/classes/type
생성자·소멸자: #/learn/lifetime/constructor
접근 지정자: #/learn/access/where
설명과 실습은 현재 강의 1~5장 및 기존 시험 유형에 맞춰 새로 작성했습니다.
참고한 학습 방식: https://o3oc4t.github.io/cpp-midterm-practice/classes.html
참고 사이트의 장별 범위는 이 자료와 다르므로 참조·복사 생성자·동적 객체를 필수 범위로 추가하지 않았습니다.
개념 실습은 정해진 예제의 상태를 시각화합니다. 임의 코드 실행기는 아닙니다.
학습 저장 키 cpp-paper-concepts-v1은 기존 시험 답안 저장과 분리되어 있습니다.

컴파일·로그인·서버·유료 API 없이 정적 파일로 동작합니다.
코드 답안의 알려진 형식만 비교하며 미등록 표현은 직접 확인으로 남깁니다.
학생 답안은 서버에 전송되지 않습니다. 다른 기기나 브라우저와 동기화하지 않습니다.

개발 및 확인
npm ci
npm test
npm run test:browser
npm run dev                 (http://127.0.0.1:4185)
npm run build               (배포 파일: dist)

배포 시 HTML 안에 CSS와 번들 스크립트를 함께 담습니다.
GitHub Pages의 개별 파일 캐시에 이전 디자인이 남아 화면이 섞이는 현상을 방지합니다.
esbuild는 배포 파일 생성에만 사용하며, 사이트 실행 시 별도의 서비스를 호출하지 않습니다.

문항 데이터: src/paper1.js ~ src/paper5.js
강조 표시와 자료 목록: src/sources.js
핵심 정리: src/study.js
채점: src/grading.js
개념 설명·이해 확인: src/concept-content.js
실행 추적·값 변경 모델: src/concept-models.js
개념 화면·학습 기록: src/concepts.js, src/concept-storage.js

개념 검증: Node 테스트에 GCC C++17 실행 결과와 시각화 출력 비교를 포함합니다.
g++이 없는 환경에서는 해당 컴파일 검증만 건너뛰며 나머지 검증은 실행합니다.
Windows Visual Studio 2022 MSVC에서도 실행 예제 23개의 출력 결과를 확인했습니다.
브라우저 검증은 47개 설명, 퀴즈, 앞뒤 추적, 값 변경, 저장·복원,
기존 시험 답안 유지, 문제 바로가기와 360~1440px 화면을 포함합니다.

공개 사이트에는 생성한 문항과 요약을 배포합니다.
원본 PDF, Windows 빌드 결과, 로컬 검증 기록은 저장소에서 제외됩니다.
실제 교수님의 시험 문항이나 배점을 확정하는 자료는 아닙니다.
