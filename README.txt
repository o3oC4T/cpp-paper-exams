컴퓨터언어 II · 지필 모의고사

20문항 × 5회분, 핵심 정리 10개 주제.
강의 PDF의 실제 화면에서 확인한 색 강조와 사용자가 제공한 시험 유형을 바탕으로 구성했습니다.
해설과 핵심 정리에 자료명 및 PDF 쪽수를 명시했습니다.
추가 교재: 황기태의 명품 C++ Programming 3판 (C++ Programming.pdf).
교재 2장 및 3장의 해당 개념과 대조하고 해설 및 핵심 정리에 교재 쪽수도 표시했습니다.
8번과 15번은 구체적인 원문이 주어지지 않아 수업 범위에서 유형을 보완했습니다.

기능
- 객관식, 복수 정답, O/X, 한 줄 코드, 출력 예측, 코드 서술형
- 답안의 브라우저 로컬 저장, 회차별 이어 풀기, 다시 볼 문제 표시
- 제출 후 해설과 자료 근거, 서술형 직접 채점
- 입력 답안과 정답이 제외된 시험지 인쇄, 제출 후 해설 인쇄
- 비교표와 코드 예제를 포함한 핵심 정리

컴파일·로그인·서버·유료 API 없이 정적 파일로 동작합니다.
코드 답안의 알려진 형식만 비교하며 미등록 표현은 직접 확인으로 남깁니다.
학생 답안은 서버에 전송되지 않습니다. 다른 기기나 브라우저와 동기화하지 않습니다.

개발 및 확인
npm ci
npm test
npm run test:browser
npm run dev                 (http://127.0.0.1:4185)
npm run build               (배포 파일: dist)

문항 데이터: src/paper1.js ~ src/paper5.js
강조 표시와 자료 목록: src/sources.js
핵심 정리: src/study.js
채점: src/grading.js

공개 사이트에는 생성한 문항과 요약을 배포합니다.
원본 PDF, Windows 빌드 결과, 로컬 검증 기록은 저장소에서 제외됩니다.
실제 교수님의 시험 문항이나 배점을 확정하는 자료는 아닙니다.
